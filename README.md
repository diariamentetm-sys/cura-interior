# Cura Interior

Portal de autoconhecimento com questionário baseado em 12 arquétipos inspirados na psicologia analítica.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Fluxo

Home → Questionário (30 perguntas) → Resultado (arquétipo predominante, complementares, mapa e dimensões).

Progresso e resultado são salvos em `localStorage` nesta primeira versão (sem backend).
